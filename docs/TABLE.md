# '운행 1회 × 정류장' 표 (v0, 2026-11-17)

버스 한 번의 운행이 승차 정류장 하나를 지날 때마다 한 줄입니다. 예를 들어 "11/17 07:10에 7770번 경기70사1234 차량이 의왕톨게이트를 빈자리 0석으로 떠났다"가 한 줄이 됩니다. 정류장 지표(02), 모델 학습(03), 예측 웹(04)이 모두 이 표에서 출발합니다.

## 만들기

```bash
python make_table.py                      # 어제까지 중 표가 없거나 원본이 바뀐 날만
python make_table.py --date 2026-11-17    # 그 날만 다시
python make_table.py --rebuild            # 전부 다시
```

- 날짜별 표 `data/tables/passes_YYYY-MM-DD.csv`와, 이를 이어 붙인 `data/tables/passes_all.csv`가 생깁니다.
- 오늘 날짜는 수집 중이라 기본 실행에서는 빠집니다.
- 판정은 `daily_report.py`와 같은 함수를 쓰므로, 표를 정류장별로 세면 일일 점검표의 '통과·만석 도착·만석 출발·출발 애매' 숫자와 같습니다.
- 파일은 UTF-8(BOM)이라 엑셀에서 바로 열립니다. pandas는 `pd.read_csv(path, encoding="utf-8-sig")`로 읽습니다.
- `data/` 폴더는 GitHub에 올라가지 않습니다. 팀에 나눌 표는 Drive 'VODA 교통팀 자료' 폴더에 올립니다.

## 어떤 통과가 들어가나

- 평일: 출근(06:00 ~ 09:59)은 서울 밖 승차 정류장, 퇴근(17:00 ~ 21:59)은 서울 안 승차 정류장.
- 주말·공휴일: 방향별(서울행·귀가) 06:00 ~ 21:59 전체.
- 노선 기점은 '도착'이 없어서 빠집니다. 시간대 시작 전에 지난 통과, 판정할 기록이 없는 통과(앞뒤 관측이 없음)도 빠집니다. 빠진 이유별 건수는 일일 점검표 8절에 있습니다.

## 열 설명

| 열 | 뜻 | 예 |
| --- | --- | --- |
| `date` | 날짜 | 2026-11-17 |
| `weekday` | 요일 | 화 |
| `day_type` | 평일 / 주말·공휴일 / 특일 | 평일 |
| `special_note` | 특일 이유(`config.yaml`의 `special_days`) | 2027학년도 수능(…) |
| `source` | 출처. gbis = 경기 버스위치, seoul = 서울 버스위치 | gbis |
| `route` | 노선 | 7770 |
| `period` | 출근 / 퇴근 / 서울행 / 귀가 | 출근 |
| `trip_id` | 운행 번호(날짜_노선_순번). 같은 운행의 정류장 줄은 같은 값 | 2026-11-17_7770_012 |
| `vehicle` | 차량번호 | 경기70사1234 |
| `capacity_est` | 그 차량의 그날 최대 빈자리(정원 추정). 하루 내내 빈 차로 잡힌 적이 없으면 실제보다 작음 | 44 |
| `mid_start` | 시간대 중간에 노선 앞부분을 건너뛰고 처음 잡힌 운행이면 1(중간 출발 후보) | 0 |
| `trip_first_seq`, `trip_first_time` | 이 시간대에서 그 운행이 처음 잡힌 정류장 순번과 시각 | 3, 06:41:00 |
| `stop_seq` | 정류장 순번(노선 정류소 목록 기준) | 27 |
| `stop_name` | 정류장 이름 | 의왕톨게이트 |
| `stop_order`, `n_stops` | 승차 구간 안에서 몇 번째 정류장인지 / 승차 구간 정류장 수 | 7, 8 |
| `pass_time`, `pass_min` | 그 정류장을 지난 것으로 처음 잡힌 시각 / 자정부터 분 | 07:10:00, 430 |
| `arr_seats` | 도착 직전 마지막 관측의 빈자리 | 3 |
| `dep_seats` | 이 정류장 ~ 다음 승차 정류장 사이 관측 중 가장 적은 빈자리. 그 사이 관측이 없으면 빈칸 | 0 |
| `arr` | 도착 판정: full = 만석 도착, ok = 빈자리 있게 도착, amb = 판정 애매 | ok |
| `dep` | 출발 판정: full = 만석 출발, ok = 빈자리 있게 출발, amb = 판정 애매 | full |
| `full_dep` | 학습용 정답. 만석 출발 1, 빈자리 있게 출발 0, 애매는 빈칸 | 1 |

## 쓸 때 주의

- **학습·비교 기준에서 뺄 날**: `day_type`이 주말·공휴일이거나 특일인 줄. 시험(홀드아웃) 기간 12/14 ~ 12/18 평일은 학습에 쓰지 않습니다.
- **기간 나누기(2026-11-22 팀 회의)**: 학습 11/10 ~ 12/3 기록(12/4 ~ 12/6에 학습), 검증 12/7 ~ 12/11, 12/12에 학습·검증 기록을 합쳐 다시 학습, 12/13 모델 고정, 시험 12/14 ~ 12/18. 날짜로 나누므로 `date` 열로 자르면 됩니다.
- **표에 아예 없는 시간대**: 수집 공백으로 일부만 남은 시간대는 `config.yaml`의 `excluded_periods`에 적어 표에서 뺍니다. 지금은 2026-11-20 퇴근(11:15 ~ 19:54 공백)뿐입니다. 첫날 2026-11-10은 16:37에 수집을 시작해 출근 줄이 원래 없습니다.
- `full_dep`가 빈칸인 줄(애매)은 정답을 모르는 줄입니다. 학습에서 빼거나 따로 다룹니다.
- 서울 버스위치(9401)의 순번은 '마지막으로 지난 정류장'이라, 경기와 판정 방식이 조금 다릅니다(`daily_report.py` 주석 참고). 표의 판정은 이미 이것을 반영했습니다.
- `capacity_est`는 하루치 최대값입니다. 여러 날 최대값으로 바꾸는 일은 데이터 담당의 다음 작업입니다(팀원별 작업 체크리스트 데이터-12).
